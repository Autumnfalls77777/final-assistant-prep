# Python Backend Engineering

1. Inspect the existing Python version, project configuration, and dependencies.
2. Follow the repository's existing architecture and avoid unnecessary rewrites.
3. Use type hints, clear module boundaries, and Pydantic validation.
4. Keep configuration centralized and validate required settings at startup.
5. Keep the development API bound to 127.0.0.1 unless explicitly authorized otherwise.
6. Make health checks work without AI API credentials.
7. Use a virtual environment and document reproducible Windows PowerShell commands.
8. Add tests for success cases, invalid inputs, and relevant error conditions.
9. Never fabricate test results. Execute the checks and record their actual output.
10. Add dependencies only when needed and explain why.
11. Do not implement AI agents, memory, or system automation unless the active phase explicitly authorizes them.
