# Documentation Research

1. Identify the exact library and version relevant to the current project.
2. Use Context7 when available to locate relevant documentation.
3. Prefer official documentation for API behavior, installation, configuration, and security.
4. Check version compatibility before proposing dependencies or code.
5. Distinguish verified behavior from assumptions.
6. Never invent methods, configuration options, commands, or API fields.
7. If documentation cannot be accessed, state the limitation and use the most reliable available evidence.
8. Research only what is needed for the current phase.
9. Do not install new integrations or implement later-phase features merely because documentation is available.
